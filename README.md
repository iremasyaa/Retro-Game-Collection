# Retro-Game-Collection
Neon atari salonu temalı, tarayıcıda oynanan, 10 oyun içeren retro koleksiyon: 3D satranç, tavla ve dama, Amiral Battı, Mayın Tarlası, Adam Asmaca ve daha fazlası. Bilgisayara karşı 3 zorluk seviyesi, 2 kişilik mod, piksel grafikler ve retro müzik. Kurulum yok, tek HTML dosyası, telefonda da internetsiz çalışır.
